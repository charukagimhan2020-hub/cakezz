## Interfaces (exact function signatures / endpoints / tables touched)
Page: `GET /monitor/` (admin session only; opened in a new tab by the admin toggle).
Proxy `GET /monitor/api.php?r=...` (admin session only, GET only, JSON, `Cache-Control: no-store`): `poll` (toggle from the database + health + newest review + 20 history rows, one call), `latest` -> RuleLock `GET /audit-log/latest`, `list` -> `GET /audit-log?limit=20`, `detail&id=<order_id or CZ-ref>` -> `GET /audit-log/<id>`, `summary` -> `GET /dashboard/summary`, `info` -> `GET /pipeline/info`, `health` -> `GET /health`. `poll` returns `{ok, toggle, mock, health:{up,error}, latest, latest_status: ok|none|error|unknown, latest_error?, list[], list_error?}`; when the toggle is OFF it returns only `{ok, toggle:false, ...}` and does not call RuleLock.
Reads (database): `platform_settings.rulelock_enabled` through the shop's `rulelock_enabled(true)`. Reads RuleLock only with `RULELOCK_URL` + `RULELOCK_API_TOKEN` from the shop environment (never sent to the browser).
Mock (`RULELOCK_MOCK=1`): serves `mock.json`; a new sample order every 12 s (accept, void_discount, hold, reject); `/monitor/?i=0..3` pins one.

## Decisions (anything you chose because the brief was unclear)
- One combined `poll` call every 2 s (instead of 3 browser calls) so a sleeping RuleLock is hit once per poll; summary counters refresh every 10 s. The individual proxy routes from the brief also exist.
- No screenshot was attached, so the layout follows the colors and structure in docs/BRIEF.md, not the proposal image.
- Page hardening: `Content-Security-Policy: default-src 'self'` (no inline script or style), all RuleLock text inserted with `textContent`.
- When the toggle is OFF the page still checks the toggle every 2 s (cheap database read) so it resumes by itself.
- When RuleLock is down the last data stays visible but dimmed, with a red banner.
- Customer shown in history = `account_username` (the list endpoint has no customer name); the detail view uses `customer_name`.
- "Reviewed" counter = `components.enforcement_engine.audit_log_entries` (24 h), "Blocked / held" = `threats_blocked`.
